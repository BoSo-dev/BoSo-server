파일: `data/policies/k-pass.v1.json`. 실제 정책이며 형식 예시가 아니다. 검수는 공식 자료의 대조와 자동화 보조로 수행했으며 기관 담당자의 승인을 의미하지 않는다.

- [행정안전부 API 안내](https://www.data.go.kr/data/15113968/openapi.do): 이용허락범위 제한 없음. 인증키는 루트 `.env`에서만 읽고 요청 헤더로 사용했으며 저장하지 않았다.
- `serviceDetail`, 서비스 ID `161300000104`: 1건 조회. 수정일 `2026-05-08`, 국토교통부 소관, 카드 발급 후 공식 앱·누리집 가입, 상시 신청을 확인했다. API 원문 전체·인증키·요청 URL은 파일에 저장하지 않았다.
- [국토교통부 최초 시행 발표](https://www.molit.go.kr/USR/NEWS/dtl.jsp?id=95089728), [정부 정책 달력](https://www.korea.kr/news/policyNewsView.do?newsId=148928793): 사업 최초 시행일 `2024-05-01`을 교차 확인했다. 현재 파일의 시작일은 사업 시행일이며 검수일·2026년 확대 시행일과 구분한다. 이 버전을 과거 환급 기준의 근거로 사용하지 않는다.
- [2026년 국토교통부 확대 안내](https://www.korea.kr/news/policyNewsView.do?newsId=148958906), [전국 확대 발표](https://www.molit.go.kr/USR/NEWS/dtl.jsp?id=95091662): 기존 정률 안내만으로 현재 혜택을 설명할 수 없음을 확인했다. 발표 수치나 문구·이미지는 등록 파일에 복제하지 않는다.

이번 등록은 카드 발급·가입·등록의 공통 절차 안내에 한정한다. API의 환급률·일/월 횟수 상한을 현재 기준으로 확정하거나 자동 계산하지 않는다. 새 제도별 금액과 적용 기간을 확인하면 별도 검수 후 연속 버전을 추가한다. 종료일이나 신청 마감일은 만들어 넣지 않는다.

카드 미보유자가 가입 안내를 볼 수 있도록 카드 보유 조건을 강제하지 않는다. 거주지 세부 조건·가입 상태·이용 실적 등은 추가 확인 대상으로 남기며 `requires_confirmation=true`다. 따라서 이 데이터만으로 맞춤 정책의 적격 확정이나 To-Do 자동 생성이 보장되지 않는다.

## 기후동행 관련 등록 보류

기후동행카드 30일권·후불·단기권·기후동행패스는 서로 다른 정책으로 관리한다. [서울시 패스 안내](https://news.seoul.go.kr/traffic/archives/518138)는 공공누리 제4유형을 표시한다. 기존 조사 문서인 [데이터.md](../데이터.md)에 기록한 이용 범위와 기간의 불일치 사항을 해소하기 전에는 `reuse_confirmed=true`로 처리하거나 실제 정책 파일에 넣지 않는다. 원문·이미지는 복제하지 않는다.

## 실행

파일 검증은 DB에 접속하지 않는다.

```powershell
uv run python -m scripts.import_policies data/policies/k-pass.v1.json
```

등록은 기존 CLI를 사용하고 한 트랜잭션으로 처리한다. 같은 파일 재등록은 기존 버전을 변경하지 않고 건너뛴다. 인증·스키마·기존 회원 데이터는 변경하지 않는다.

```powershell
uv run python -m scripts.import_policies data/policies/k-pass.v1.json --apply
```
